### 🚫 เกณฑ์ความผิดปกติในโลกความเป็นจริงที่ถูกคัดออก:
1. **ซื้อหน้าร้านแต่เก็บเงินปลายทาง (COD) (402 รายการ):** การซื้อสินค้าที่หน้าร้านไม่มีการจัดส่งพัสดุ จึงไม่มีปลายทางให้เก็บเงิน
2. **คำสั่งซื้อสถานะ "ยกเลิก" แต่มีจำนวนวันจัดส่ง > 0 วัน (364 รายการ):** คำสั่งซื้อที่ถูกยกเลิก ไม่มีการจัดส่งสินค้าจริง จึงไม่ควรมีระยะเวลาจัดส่ง
3. **ซื้อหน้าร้านนอกเวลาเปิดทำการ (501 รายการ):** มีรายการซื้อหน้าร้านช่วงเวลา 22:00 – 08:00 น. (เช่น 01:36 น., 02:15 น.) ซึ่งร้านค้าปลีกปิดทำการ
4. **ผู้เยาว์อายุต่ำกว่า 20 ปี ชำระด้วยบัตรเครดิต (294 รายการ):** ตามเกณฑ์ของธนาคารแห่งประเทศไทยและกฎหมายไทย ผู้ถือบัตรเครดิตหลักต้องมีอายุ 20 ปีบริบูรณ์ขึ้นไป

## 🚀 ขั้นตอนการเปิดใช้งานเป็นเว็บไซต์บน GitHub Pages

1. **สร้าง Repository ใหม่บน GitHub**
   * เข้าสู่ระบบที่ [github.com/new](https://github.com/new)
   * ตั้งชื่อ Repository (เช่น `sales-data-analytics`) และเลือกเป็น **Public**

2. **เชื่อมต่อและ Push โค้ดขึ้น GitHub**
   เปิด Terminal / PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git branch -M main
   git push -u origin main
   ```

3. **เปิดใช้งาน GitHub Pages**
   * ไปที่หน้า Repository บน GitHub &gt; คลิกแท็บ **Settings**
   * เลือกเมนูด้านซ้าย **Pages**
   * ในส่วน **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
   * รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น: `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
